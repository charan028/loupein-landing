What the chart already holds

Dental software stores everything and volunteers nothing. Warfarin sits on the medication list, active as of 2026, while a visit transcript from the same year says the patient stopped taking it. The chart waits for the clinician to go looking — gloves on, patient in the chair.

One agent walks the whole record

The useful question is not "what is in this chart?" but "given what I am about to do, what deserves a second look?" Four agents answer it: the Context Interpreter reads the stated intent, the Guardian Investigator runs ReAct over nine deterministic record tools, the Skeptic argues against every candidate — the finder is biased toward finding — and the Assist Composer ships only what survives, adding no advice.

The Skeptic answers in types

Every candidate faces TypeSafe's Jev model. Not a paragraph of hedging, a typed judgment: SURFACE, DISMISS, or VERIFY. A card only ships if it survives the argument against it; if nothing survives, the dentist hears nothing. Silence is a result.

How it works

  1. Next.js
  2. FastAPI
  3. LangGraph
  4. Gemini investigation + vision+TypeSafe Jev decisions
  5. Supabase Postgres
  • 100% synthetic data, seeded from db/seed.sql.
  • The Guardian chooses its tools dynamically; no scripted path.
  • Every agent event is persisted; the trace above is a real row set.
